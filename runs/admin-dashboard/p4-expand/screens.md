## 기기별 변환 메모
- 태블릿: 사이드 내비 대신 상단 헤더(로고·제목·갱신 시각·라인 선택). 라인 칩 6개 → "전체 라인" 버튼 1개(Large 48, 터치 영역 기준). 모든 버튼 Large(48). 13px 글자는 14px(Label 1) 또는 Caption 1로. 카드 배치는 웹과 같은 3열 + 2열.
- 모바일: 1열. [주목] 처리 목록은 항목마다 상태·경과 → 설비명 → 설명 → 전체 폭 버튼 순. 히어로 숫자는 Display 1 대신 Title 3(24). 점검 카드는 링 + 미점검 요약 후 라인별 막대. 2주 차트는 날짜 라벨 대신 시작일·하루 평균·오늘 값만 표시. 수리 단계 라벨 "재가동 확인"은 두 줄.
- 공통: 정지 설비는 아이콘 + 빨간 글자(★1), 상태 색 테두리·옅은 바탕 없음(⑩⑪), 화면당 [주목] 1개(⑫).
